# 用户旅程草案｜R2

这些旅程只串联 Requirement ID，不重新定义领域或审批规则。

<a id="J-01"></a>
## J-01｜首次使用，不配外部服务

**状态：目标**

打开应用 → 进入置顶/默认工作区 → 可以只用公司＋岗位创建第一个 Opportunity（JD 后补），或创建 Project、Employment，或在 Wiki 的明确 Personal/Cognition 范围写第一条知识 → 保存 → 回到当前对象。

不要求先配置 AI、Search、飞书。空表单取消不产生记录。

<a id="J-02"></a>
## J-02｜从工作材料形成长期积累

**状态：目标**

建立独立 Project，或在 Employment 里关联同一个 Project → 按需建立 Person 和项目职责 → 添加/引用明确所属的 Raw → 手工写 Wiki，或发起 AI 比较 → 逐条处理 Wiki Proposal → 回看当前知识、来源和历史。

Project 换 Employment 时旧协作保留历史；来源更正后相关当前知识提示依据待复核，不自动改正文。误导入/敏感 Raw 可按 DM-38 纠正归属或清除。

<a id="J-03"></a>
## J-03｜按现实推进一次机会

**状态：目标**

创建公司＋岗位（JD 可后补） → 按现实顺序记录：准备简历/不准备、沟通、首次投递、直接约面、真实面试、直接收到 Offer 等 → 每个真实事件更新对应对象和必要阶段 → 明确当前结果。

这是现实记录，不是强制向导：不补假 Submission、不猜日期。晚录旧历史不按录入顺序倒退阶段；结束后仍可补旧历史或记录真实后续。误操作纠正原 Opportunity，真正重新申请才新建 Opportunity。

<a id="J-04"></a>
## J-04｜完成、导出并如实记录实际发送材料

**状态：目标**

从 Opportunity 进入当前 Resume → 模板或复制指定普通版本 → 连续纸面编辑/可选 AI → 自动保存 → 可选命名版本 → 导出可追溯 PDF → 现实发送 → 登记首次 Submission 或后续材料发送。

如果发送 A 后当前稿已改成 B，选择 A 的导出物/实际文件；A 已丢失则如实记录文件缺失，不拿 B 冒充。后期首次建稿、晚补首次投递、后续补发不互相冒充。

<a id="J-05"></a>
## J-05｜真实面试与模拟的完整回路

**状态：目标**

现实确认有一轮真实面试 → 可先“待排期” → 保存 Preparation → 可选多次 Simulation → 导出选定背景到外部练习 → 带回模拟 Transcript/Review → 真实面试后保存/更正 Transcript → 手工或 AI 形成 Final Review → 审阅有依据的 Research Proposal。

Simulation 中用户发现真实个人经历漏记时，可主动选定片段、确认现实含义后形成 Personal/Cognition 或 Project Wiki Proposal；模拟面试官虚构不能回流。误完成/误取消修正同一轮，不造假第二轮。

<a id="J-06"></a>
## J-06｜Offer、谈薪、接受与实际入职

**状态：目标**

现实收到 Offer（即使没有前序 Submission/Interview） → 保存原件/当前条件 → 可选 AI 分析 → 记录谈薪沟通 → 更新正式当前条件 → 用户接受时冻结当时接受依据 → 结束后继续记录真实条件变化/报到沟通/撤回 → 现实入职后独立创建 Employment。

接受、后来条件变化、招聘方撤回和真正入职分别是不同事实。

<a id="J-07"></a>
## J-07｜研究或导入资料

**状态：目标**

Research：确认公开/获准查询范围 → 查看真实 Search 结果 → 另行确认/授权模型整理 → 按 CompanyResearch 或 OpportunityResearch 目标组审批。提升到公司共享内容时明确共享范围；机会 Wiki 不维护重复正文。

Import：从所属对象选择本地/飞书资料 → 读取候选/正文 → 预览 → 确认保存 Raw → 需要时另发起 AI。导入、AI 外发和正式知识写入是不同动作。

<a id="J-08"></a>
## J-08｜在原任务里记录使用反馈

**状态：目标**

打开反馈 → 写一句话/自选截图 → 保存 → 回原任务；之后可查看、补充、导出、归档或按 DM-38 明确清除。反馈层和底下业务表单分别保护输入；保存未知不重复创建。

<a id="J-09"></a>
## J-09｜日常备份与恢复

**状态：目标**

查看资料位置、最近恢复点和自动备份状态 → 可启停周期自动备份或手动建立恢复点 → 查看完整/不完整状态 → 选择一个副本 → 在安全位置核验 → 明确影响 → 执行普通恢复 → 打开恢复后的资料并显示仍缺内容。

这是日常恢复旅程，不等同于旧系统正式迁移。正式迁移需另遵 MG-07 的实际数据盘点、隔离演练和授权。
