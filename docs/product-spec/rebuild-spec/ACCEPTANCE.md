## 端到端旅程

| 旅程 | 重点验收 |
| --- | --- |
| [J-01](JOURNEYS.md#J-01) 首次使用，不配外部服务 | 无 JD 也能创建真实 Opportunity；不配置 AI 仍能完成手动记录。 |
| [J-02](JOURNEYS.md#J-02) 从工作材料形成长期积累 | Raw/来源→Wiki→历史；换任职、来源变化、清除敏感资料都不丢 owner。 |
| [J-03](JOURNEYS.md#J-03) 按现实推进一次机会 | 先沟通/直接约面/直接 Offer/晚录历史均不需要伪造前序事件。 |
| [J-04](JOURNEYS.md#J-04) 完成、导出并记录发送材料 | 连续编辑、导出物身份、实际发送 A 与后来当前 B、缺失原文件形成完整闭环。 |
| [J-05](JOURNEYS.md#J-05) 真实面试与模拟 | 待排期→准备→模拟→带回文字→真实面试→复盘→建议；误终态修正同一轮。 |
| [J-06](JOURNEYS.md#J-06) Offer、谈薪、接受与入职 | 接受绑定当时条件；接受后条件变化/撤回与实际 Employment 分开。 |
| [J-07](JOURNEYS.md#J-07) 研究或导入 | Search/Import/AI/Proposal 分层；机会研究唯一 owner；有限任务授权不越权。 |
| [J-08](JOURNEYS.md#J-08) 记录反馈 | 不丢底层输入、定位正确对象、保存 unknown 不重复、职业 Context 隔离。 |
| [J-09](JOURNEYS.md#J-09) 日常备份恢复 | 自动/手动恢复点、完整性、恢复后可用状态；与正式迁移分开。 |

## 证据层级

规格一致性、静态代码/测试定义、隔离自动化、真实浏览器、真实外部服务、正式用户数据恢复是不同证据层级。任何 PASS 必须注明实际执行层级和环境；本 R2 文件自身不包含 PASS。
