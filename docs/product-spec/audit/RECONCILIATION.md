## 4. 直接修正的规格矛盾

这些不需要用户重新决定：

1. `Fact` 统一叫“事实陈述”，不再由 UX 显示成“已确认事实”。
2. 用户手工保存直接生效；AI 提议才走 AI-10。手工把内容提升到 CompanyResearch 不二次审批。
3. R1 PD-09 中“不能纠错就另建轮次”的非法选项被删除；现实新轮次才新建对象。
4. 首页只有一个 owner：置顶模块就是默认首页偏好，没有第二份“默认进入”状态。
5. Research 的支持摘录、用户确认、独立核验等是可并存维度，不互相覆盖。
6. “忽略”与“拒绝”分开：忽略仍待处理，拒绝结束 Proposal。
7. J-09 日常恢复与 MG-07 正式旧数据迁移分开。
8. Acceptance 不再把“返回所属对象”扩大成所有返回动作，也不把结构化隐私过滤夸大成任意自由正文绝对脱敏。
