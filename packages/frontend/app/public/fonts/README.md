# Career Resume Sans

Derived from the Source Han Sans CN variable WOFF2 bundled in the user-supplied Miaoda resume application. License: SIL Open Font License 1.1; see LICENSE.txt and https://github.com/adobe-fonts/source-han-sans/blob/release/LICENSE.txt.

Source SHA256 and derivative generation are recorded in the verification document. Glyph outlines, spacing and variation axes are unchanged. The family is renamed to Career Resume Sans. Duplicate compatibility/radical Unicode cmap aliases that share a glyph with the canonical Chinese character are removed: Chromium otherwise chooses the radical codepoint for PDF ToUnicode, producing visually correct but incorrectly copied Chinese text. No resume content is embedded in this font.

The same local font is served to the editor and supplied to the PDF engine through its fixed, digest-checked resource; no external font download is permitted. Ordinary/basic historical PDFs keep their existing font selection.
